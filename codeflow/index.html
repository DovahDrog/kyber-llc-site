Workflow

Built around how inspectors actually work.

Today, field staff often take photos and then stop later to type notes, gather property data, match issues to code sections, and assemble review-ready case materials. CodeFlow compresses that field-to-office gap.

See it, photograph it

Capture site photos and attach them to the inspection case with address, parcel, owner, and case context where available.

Talk through the observations

Use voice or typed notes to describe vegetation, debris, storage, screening, access, or other field conditions.

Generate possible findings

CodeFlow organizes evidence, suggests possible issue categories, and flags uncertainty that must be checked by staff.

Review before official action

Authorized staff verify facts, object identity, code citations, cure periods, and final case-packet language before any posting, mailing, or official action.

Critical safeguard

AI suggestions are not final enforcement decisions.

CodeFlow is designed to assist authorized municipal staff. It should say "possible violation" until staff verify the site condition, object identity, applicable code, responsible party, cure period, and case-packet language.

Real-world example

Ambiguity must be visible.

If an object looks like a black cable but may be a black water hose, the system must flag uncertainty and require inspector confirmation before citation. The correction belongs in the audit trail.
